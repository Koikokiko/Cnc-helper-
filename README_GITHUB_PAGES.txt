# CNC Helper — публикация на GitHub Pages

В архиве уже подготовлен комплект для установки как веб-приложения (PWA). Основной файл переименован в `index.html`.

## Публикация
1. Распакуйте архив.
2. Загрузите **все файлы из этой папки** в корень репозитория GitHub (не сам ZIP).
3. В GitHub откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем Save.
5. Дождитесь публикации и откройте выданный GitHub Pages URL в Safari на iPhone.

## Установка на iPhone
1. Откройте опубликованный адрес именно в Safari.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» (при наличии — включите «Открывать как веб-приложение»).
4. Нажмите «Добавить».

Иконка берётся из `apple-touch-icon.png`. После установки приложение открывается в отдельном окне без обычной панели браузера. Service worker кэширует оболочку приложения и позволяет открыть её при временном отсутствии сети. Внешние библиотеки и отдельные функции (например, загрузка/обработка некоторых 3D-форматов) могут по-прежнему требовать интернет; данные CNC, как и прежде, хранятся в браузерном хранилище устройства.

## Обновление
При следующем выпуске заменяйте файлы в репозитории новыми. Для принудительного обновления кэша увеличивайте `CACHE_NAME` в `sw.js`. В этой сборке используется `cnc-helper-v142-10`.

Важно: после переезда на новый домен/путь GitHub Pages установите приложение с опубликованного URL заново. Не открывайте `index.html` напрямую из приложения «Файлы» — PWA-установка и service worker работают через HTTPS-хостинг.
